# AI Sign Language Translator

A real-time AI-powered sign language translation system that recognizes Pakistani Sign Language (PSL) alphabets using computer vision and machine learning.

## Features
- Real-time hand gesture recognition
- PSL alphabet detection (A-Z)
- Flutter mobile app frontend
- Python/FastAPI backend
- MediaPipe + Random Forest ML model

## Tech Stack
- **Backend:** Python, FastAPI, MediaPipe, Scikit-learn
- **Frontend:** Flutter (Dart)
- **ML Model:** Random Forest Classifier

## Setup
### Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```
### Frontend
```bash
cd frontend
flutter pub get
flutter run
```
